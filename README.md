# Список задач (To-Do List)

Простой сайт-список задач в одном файле `index.html`: без сборки, без зависимостей, без сервера.

**Демо:** https://bobbeker72-del.github.io/-todo-list/

## Возможности

Обязательные:
- добавление задач (кнопка или Enter, пустые задачи не добавляются);
- отметка задач выполненными (чекбокс или клик по тексту);
- удаление задач;
- сохранение после обновления страницы (`localStorage`).

Дополнительные:
- **Редактирование** задачи: кнопка с карандашом или двойной клик по тексту; Enter сохраняет, Esc отменяет;
- **Отмена удаления** (6 секунд): кнопка «Отменить» или Ctrl/Cmd+Z; работает и для «Удалить выполненные»;
- фильтры «Все / Активные / Выполненные» (выбранный фильтр запоминается), счётчик активных задач;
- синхронизация между вкладками без перезагрузки, без потери данных;
- чёрно-оранжевое оформление в «бэтмен»-стиле (оранжевое свечение, летучая мышь в заголовке и на вкладке браузера);
- адаптивная вёрстка, крупные области нажатия на сенсорных экранах;
- управление с клавиатуры, имена элементов для скринридеров, контраст по WCAG AA, учёт `prefers-reduced-motion`;
- защита от XSS (весь пользовательский текст выводится как текст, а не как HTML);
- устойчивость к повреждённым данным в хранилище и к недоступному `localStorage`.

## Запуск

Откройте `index.html` в браузере. Для публикации включите **Settings → Pages → Deploy from a branch → `main` / root**.

## Технологии

Чистые HTML, CSS и JavaScript (ES5-совместимый код, без библиотек и фреймворков).

## Как разрабатывалось и какие AI-инструменты использованы

- **Claude (Anthropic)** — генерация кода сайта, ревью и исправление найденных дефектов.
- Автоматическая проверка в Chrome через Playwright: функции, граничные случаи, повреждённые данные, две вкладки, клавиатура, мобильная вёрстка, контраст цветов.

Что проверено, а что нет: 146 автоматических проверок в Chrome (стабильно проходят); в Firefox и Safari сайт не проверялся.

Примечание: для заголовка используется шрифт Impact (есть в Windows и macOS); если его нет в системе, подставляется обычный sans-serif, сайт при этом работает так же.
